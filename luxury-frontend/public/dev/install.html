Dopo «Scarica comunque»
  1. Chrome → icona Download (freccia in alto a destra).
  2. Tocca saloni-luxury.apk.
  3. Se chiede permesso: Impostazioni → App → Chrome → Installa app sconosciute → Consenti.
  4. Play Protect → Installa comunque (se compare).
  5. Apri l’app dalla home. Mac acceso con npm run dev + backend.
